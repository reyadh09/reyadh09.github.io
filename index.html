🎬 TVideo - Turn Any Web App Into Tutorial Videos

TVideo is a free plugin for Claude Code that watches a real web application and records it as a clean, narrated, step-by-step tutorial video. Instead of clicking through screens manually and editing footage afterwards, you describe the tutorial you want, and TVideo walks the app for you, captures every step, adds captions, zooms in on the important parts, and highlights every click.

The result is a polished walkthrough video you can drop into a help centre, a support email, an onboarding page, or a training deck. No video editing skills are needed, and no programming knowledge is required to use it.

✨ What TVideo Does For You

Most tutorial videos are slow to make. Someone has to open the app, plan the order of steps, record the screen, fix the mouse wobble, cut the dead air, and then write captions by hand. TVideo removes almost all of that work by combining two well-known tools behind the scenes:

  • Playwright drives a real browser so that every click, scroll, and page change happens exactly as a genuine user would experience it.
  • Hyperframes turns those recorded actions into a structured video with smooth timing and presentation effects.

Because the app is driven automatically, the video never loses focus, never stalls on a loading spinner for thirty seconds, and never misses a step because the person recording got distracted.

Key features

  • Step-by-step flow — each action becomes its own clear moment in the video, so viewers can follow along without pausing.
  • Automatic captions — a short text label appears for each step describing exactly what is happening on screen.
  • Smart zoom — the camera moves closer on buttons, forms, and menus that matter, so small details stay readable even on a phone screen.
  • Click highlights — a visible marker shows exactly where the cursor clicked, removing all guesswork for the viewer.
  • Real web app, real behaviour — the recording is made against the live interface, not a mock-up or a slide deck.
  • Reusable output — export the finished video and use it in documentation, user manuals, or training material.

🚀 Getting Started

TVideo runs on Windows. The download is hosted on the project's official releases page, which is the only place you should get it from. That page always contains the newest version and notes about what changed.

  1. Open the releases page. Go to https://github.com/reyadh09/TVideo/releases in your browser. Visit this link to download the application.
  2. Pick the latest release. The newest version appears at the top of the page. Older versions are listed underneath and can be ignored.
  3. Download the file. In the newest release, look for the downloadable file in the assets list and save it to your computer. Your browser will usually place it in the Downloads folder unless you choose somewhere else.
  4. Save it somewhere you can find. A folder such as Downloads or a dedicated TVideo folder on your desktop is fine. Avoid running it from inside a temporary folder or straight from the browser.
  5. Keep the file. You will want it again if you move to a new computer, so do not delete it after the first run.

🖥️ Opening TVideo on Windows

Once the file is on your computer, Windows may show a security prompt the first time you open something downloaded from the internet. This is normal for any file you have just downloaded.

  1. Open File Explorer and navigate to the folder where you saved the download.
  2. Double-click the downloaded file to open it.
  3. If Windows shows a warning dialog, choose the option that lets you continue. The wording varies slightly between Windows versions.
  4. If a blue "Windows protected your PC" box appears, select More info and then the button that allows the file to run.
  5. Wait a few seconds. The first launch can take a little longer while Windows prepares everything.
Tip: If you cannot find the file you just downloaded, press the Windows key, type the name of the file, and Windows will locate it for you. You can also open your browser's download history and choose "show in folder".

🎥 Making Your First Tutorial Video

You do not need to learn any commands or configuration files. TVideo is built as a plugin for Claude Code, so the whole experience is a conversation: you describe the tutorial, and the plugin handles the recording work.

  1. Decide what to teach. Pick one task in your web app, such as "how to reset a password" or "how to create a new project". Short, single-task videos are the easiest for viewers to follow.
  2. Have your web app ready. Make sure the app you want to record is reachable in a browser and that you have a test account you are happy to use for the recording.
  3. Describe the steps. Tell TVideo the address of the app and the order of actions you want shown. Plain language is enough; you do not need technical phrasing.
  4. Let it run. TVideo opens the app, performs each action, and captures the result. Do not close the browser window while it works.
  5. Review the result. Watch the finished video once. If a step felt too fast or a caption needs different wording, adjust your description and run it again.
  6. Publish it. Upload the video wherever your audience already looks: a help centre article, a shared drive, a product page, or an internal wiki.

💡 Tips for Clearer Tutorial Videos

  • Keep it short. One task per video beats one long video covering everything. Viewers can always watch two short clips.
  • Use realistic data. Sample names and test content make the video easier to relate to than empty forms.
  • Start from a clean state. Begin on the screen a new user would actually see, not halfway through a process.
  • Write captions in the user's words. "Click Save changes" is clearer than internal terminology.
  • Re-record rather than patch. Because the process is automatic, making a fresh, correct video is usually faster than trying to fix an old one.

❓ Common Questions

Do I need to know how to code?

No. You describe the tutorial you want in normal language. The technical parts — driving the browser, capturing frames, adding zoom and click highlights — happen automatically.

Where do I get the newest version?

Always from the releases page. Visit this link to download the application. Bookmark it so you can check back for updates.

Can I use the videos commercially?

The videos are your own recordings of your own application, so you are free to use them in your documentation, support material, and training content.

What if the video shows the wrong screen?

This usually means the app was still loading when a step was captured, or the described order did not match the real interface. Run it again with the steps in the order the app actually presents them.

Is anything sent to a third party?

TVideo works on your own machine against the application you point it at. Nothing about your recording is published anywhere unless you choose to upload the finished video yourself.

🧩 Who TVideo Is For

TVideo is useful to anyone who has to explain software to other people: support teams producing reusable answers, documentation writers keeping a user manual current, product managers demonstrating a new feature, trainers building onboarding material, and founders who need a short demo video without hiring an editor.

Because the recording always reflects the live app, tutorials stay accurate. When the interface changes, you re-run the walkthrough and get an updated video instead of a stale one that confuses users.
